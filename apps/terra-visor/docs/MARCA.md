# Identidad visual

Referencia autorizada: https://www.terraformings.co/

Estilos comprobados en el sitio original el 18 de octubre de 2026:
- Azul principal: #0e2a47.
- Naranja: #f7941d.
- Montserrat para títulos e Inter para texto y controles.
- Logotipo blanco original, incorporado como archivo local desde https://www.terraformings.co/assets/logo_blanco-GD1gfTMt.png.

La nueva cabecera y los controles usan esta identidad. El plano conserva su geometría y los colores comerciales por estado. La imagen inferior se mantiene sin enlaces. El sitio comercial y el Site previamente publicado no se modificaron.

Vista comprobada con el Excel local de 104 lotes. La lectura remota de SharePoint requiere configurar las variables en Vercel y probar las credenciales.
